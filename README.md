# medieval-trade-guild-management-game-(trading-simulation-project)

##  프로젝트 개요

상단 운영 게임은 불확실한 선택 속에서 수익을 극대화하는 무역 경영 시뮬레이션 게임입니다.  
플레이어는 아버지를 대신해 상단을 운영하며, 랜덤 보급품과 위험한 무역 루트를 통해 최대 ROI(수익률)를 목표로 합니다.

## 설계

### 기능 구현 목록

#### 상단 초기 상태 표시
- [x] 시작 날짜를 표기한다
- [x] 초기 골드, 명성, 창고 용량, 보유 행상대 수를 출력한다
  - 골드(재화)는 음수가 될 수 없다
  - 명성치는 음수가 될 수 없다
  - 현재 용량은 최대 용량을 넘을 수 없다
  - 용량은 음수가 될 수 없다
  - 무게는 음수가 될 수 없다
- [x] 초기 재고(곡물, 목재, 향료)를 출력한다
  - 재고 아이템은 0 이하가 될 수 없다
- [x] 값이 음수로 표시되지 않도록 예외 처리

#### 랜덤 보급 상자 구매

- [ ] 랜덤 보급 상자 가격을 출력한다 500G
- [ ] 플레이어 입력 처리 (Y/N)
- [ ] 대소문자 구분 없이 처리
- [ ] 잘못된 입력 예외 처리
- [x] 상자 구매 가능 여부를 확인한다
- [x] 상자를 구매한다
- [x] 보상을 생성한다
- [x] 플레이어의 골드가 부족할 시 구매 불가 메시지를 출력한다
- [x] 플레이어의 명성치가 부족할 시 구매 불가 메시지를 출력한다
- [x] 상자 개봉 후 획득 재고를 출력한다
- [x] 재고 업데이트 후 골드 차감한다

#### 재고 업데이트 및 출력

- [ ] 재고 수량 변경 시 창고 용량을 확인한다
- [ ] 창고 초과 시 경고 메시지
- [x] 각 자원(Gold, 곡물, 목재, 향료) 업데이트 후 표시한다
- [x] 음수 재고 방지


#### 거래 의뢰서 표시

- [x] 하루 시작 시 거래 목록 출력한다
- [x] 도시명, 납품 요구량, 보상 골드, 명성, 소요 기간 표시
- [x] 주문 번호 입력를 받는다
- [ ] 0 입력 시 모두 거절한다
- [ ] 잘못된 번호 입력 예외 처리


#### 행상대 배정

- [x] 주문 수락 시 행상대 선택
- [x] 사용 가능한 행상대를 출력한다
- [ ] 이미 출정 중인 행상대 선택 제외한다
- [ ] 잘못된 입력 예외 처리
- [ ] 출정 메시지 출력한다
- [x] "OO의 행상대가 XX 도시로 출정합니다."


#### 출정 진행

- [ ] 하루마다 출정 진행 일수를 증가한다
- [x] 목표 일수 도달 시 납품 완료시킨다
- [x] 완료 시 골드, 명성 지급 및 재고를 차감한다
- [x] 중간 진행 상황 출력한다 (예: 1/3일 진행)

#### 창고 유지비 및 급료 지출

- [ ] 하루 종료 시 골드 차감한다 (예: -10G)
- [ ] 골드 부족 시 경고 메시지를 출력한다
- [ ] 일일 비용 내역을 출력한다

#### 하루 종료 및 이벤트

- [ ] 하루 종료 시 특별 이벤트 발생 여부 체크
- [ ] 랜덤 보급 상자 재구매 선택
- [ ] 다음 날 시작 준비

#### 입력 유효성 & 예외 처리 체크

- [ ] Y/N, 주문 번호, 행상대 선택 입력 예외 처리
- [ ] 골드 부족 시 구매/출정 제한
- [ ] 재고 부족 시 거래 불가
- [ ] 창고 용량 초과 방지

###  MVP 루프
- 물건 구매 = 랜덤 보급 상자
- 행상대/용병을 고용해 이동
- 자원 판매 = 골드 획득
- 명성치 ↑ = 더 좋은 등급 상자 구매 가능
##### day loop flow

- 상단 현황 출력
- 랜덤 보급 상자 구매 여부 입력
- 재고 갱신 및 보고
- 일일 의뢰 목록 표시
- 주문 선택 및 행상대 배정
- 출정 결과 반영 / 이벤트 발생
- 유지비 및 급료 지출
- 일일 보고서 출력
- 다음 날 진행 여부 확인

#### 추가 리펙터링
- [ ] Capacity에서 current.minus(other.weight) → 음수 체크 필요
- [x] Weight 객체 상수명 오타 수정
- [ ] 예외를 던질 때 무엇이 잘못되었는지 디버깅 용이성을 위해 추가하기
- [ ] 랜덤 보급 상자 출력 방식 변경
  - 보급상자는 4 종류가 존재한다
  - 각 보급상자는 요구 가격과 명성치가 존재한다
  - 요구치에 충족하지 않은 경우 "구매할 수 없습니다"는 메세지를 반환한다.
  - 보급 상자는 하루에 1개만 구매 가능하다
- [ ] supplyBoxType -> SupplyBoxSelector 헬퍼 클래스로 불리할지 고민하기
- [ ] player.pay(type.cost) 수정하기 -> 타입별 값을 꺼내와야 하는 지 의문
- [ ] isYesInput input 수락함수 다른 키 입력 리펙토링 하기 (메세지, 키입력 값, input,outputView 재사용 편하게)
- [ ] AssignedQuest 예외처리 (상태값에 따라)
- [ ] 창고 유지비, 행상대 급료 지출 기능 구체화
- [ ] 행상대 COMPLETED 상태 필요한지 확인하기
